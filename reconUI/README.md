# Recon UI subset for Recom3 Ghost

This module includes the original `FontUtils.java` from the Recon UI module distributed with Snow2Liftie. The source file is unchanged. The build configuration and manifest were adapted for Recom3 Ghost. The rest of the Recon UI widgets and resources were omitted, except for the Open Sans Regular and Bold font files.
